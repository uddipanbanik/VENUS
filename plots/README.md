# VENUS example figures

A density profile shows where mass lies as a function of radius. Its slope
shows how rapidly density changes. The linked guide defines the additional
quantities used in each figure. PDF files provide scalable graphics and PNG
files provide image previews.

Additional terms are defined in the [plain-language glossary](../docs/TERMS.md).

The twelve PDF/PNG pairs in this directory show the example calculations. [The reproduction guide](../analysis/README.md) describes each
physical calculation, the reduced data, units, masks and plotting commands.
Run `python scripts/reproduce_examples.py` from `analysis/` to generate all twelve
pairs in `analysis/reproduced/`.
